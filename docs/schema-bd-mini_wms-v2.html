Schéma BD
mini_wms.

Deux niveaux d'isolation : le schéma public (partagé) porte les tenants et leurs droits ; chaque schéma client porte les données métier, isolées. Invariant central inchangé : le stock est dérivé des mouvements, et la production comme la réception ne font que générer des mouvements.

PK clé primaire FK clé étrangère bleu = schéma public article · mouvement · colis — génère → crée des mouvements, ne modifie pas le stock
Changements depuis la v1 — nommage français ; ajout des tables tenant / tenant_feature (schéma public, droits datés TRIAL/ACTIVE) ; materiau porte la densité ; séparation visuelle public / schéma client.
Index clés — mouvement : (article_id, etat, date_effective), (source_id, etat), (destination_id, etat), (colis_source_id), (colis_dest_id). Table qui grossit ; le reste est du référentiel.
Perf — table de snapshot (stock figé à clôture) + recalcul du delta, uniquement quand la lenteur se voit.
